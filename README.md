# My Portfolio

## About

A modern, responsive personal portfolio website built to showcase my web development projects, technical skills, and background. Features clean semantic layout structure, custom CSS animations, interactive hover effects, and responsive design optimized for standard viewports as well as 4K ultra-wide displays.

## Technologies

- HTML
- CSS
- Tailwind CSS (CDN)
